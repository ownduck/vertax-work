# Social Media Video Generate

编排技能：出图用 **image-generate-edit**，成片用 **reference-to-video**。缺项一律 HITL 停问，勿猜测素材、平台或主题后直接开跑。

适用平台：**TikTok**、**YouTube**、**Instagram**。

## HITL 流程（严格按序）

### 1. 选择目标平台

先让用户三选一（未选则停住，勿默认）：

| 平台 | 成片与文案侧重 |
|---|---|
| TikTok | 前 1–2 秒强钩子；节奏快、切口多；口语对白/字幕感；反转或卖点要早出现；偏趋势、娱乐、种草 |
| YouTube | 略完整的起承转合；开头仍要留人但可稍铺垫；信息更清楚（步骤/卖点可读）；结尾可轻 CTA（订阅/评论） |
| Instagram | 画面精致、审美统一；运镜与构图更「可截图」；品牌/生活方式感；文案偏短 caption + 话题标签 |

选定平台后，后续**视频提示词、节奏、对白密度、标题与正文**都必须按该行特点写，不能写成通用片再换皮。

### 2. 选择帖子类型

先让用户选一类（可附一句说明）。主要类型：

| 类型 | 说明 |
|---|---|
| 商品带货 | 展示商品卖点、开箱、试穿试用、转化导向 |
| 生活日常 | Vlog 感、日常片段、氛围分享 |
| 娱乐段子 | 搞笑、反转、梗、夸张表演 |
| 教程种草 | 步骤演示、评测、安利清单 |
| 品牌宣传 | 品牌调性、口号、活动预告 |
| 剧情 POV | 第一人称/短剧情冲突 |
| 热点跟风 | 挑战、趋势 BGM/动作模板 |

用户未选则停住；勿默认选商品类。

### 3. 按类型收集图片（逐张 HITL）

每张图单独询问：**「用户提供」或「自行生成」**。选提供则索要路径/URL；选生成则先调 **image-generate-edit** 生成该张，确认后再问下一张。

| 类型 | 必收图（按顺序逐张问） | 可选图 |
|---|---|---|
| 商品带货 | ① 人物图 ② 商品图 | 场景/包装图 |
| 生活日常 | ① 人物图 | 场景/道具图 |
| 娱乐段子 | ① 人物图 | 道具/反差物图 |
| 教程种草 | ① 人物图 ② 演示对象/产品图 | 步骤结果图 |
| 品牌宣传 | ① 品牌主视觉或产品图 | 代言人/人物图 |
| 剧情 POV | ① 人物图 | 场景图 |
| 热点跟风 | ① 人物图 | 趋势相关道具图 |

规则：

- 必收图未齐不进入下一步。
- 「自行生成」时：调 **image-generate-edit**；人物强调身份一致，商品强调外观可读；日常用默认模型，复杂包装/多元素版面用 pro。出图风格可略贴合已选平台（如 Instagram 更精致，TikTok 更生活感）。
- 交给 **reference-to-video** 的参考图控制在其允许张数内；多出时优先保留该类型「必收」图。

### 4. 社媒文本内容主题

HITL 二选一：

- **用户指定**：索要主题/卖点/要表达的一句话。
- **自行生成**：按**已选平台**、帖子类型与已有图片，先写出简短主题（中文即可）给用户看一眼再继续（用户未反对即用）。

主题用于：写视频剧本/分镜、以及最终帖子标题与正文。

### 5. 生成视频

1. 阅读并遵循 **reference-to-video**（时长、剧本、分镜等以其为准）。
2. 把已收集图片与主题/剧本交给该 skill；竖屏；在提示词中明确目标平台，并落实第 1 步该平台的节奏/钩子/对白/画面要求。
3. 剧本未指定时：按其规则自行生成有趣短段子再写分镜提示词（段子结构也要符合平台特点）。
4. 按其流程跑通提交与下载；勿重复提交。

若还缺静帧，先用 **image-generate-edit** 补图，再进 **reference-to-video**。

### 6. 交付物（必须全部给出）

1. **生成的视频**：本地绝对路径（reference-to-video 输出）。
2. **建议的帖子标题**：1 条，**英文**；语气贴合已选平台（TikTok 更口语抓人，YouTube 可稍完整，Instagram 更短更审美）。
3. **建议的帖子内容**：1 段**英文**正文（可含 emoji/话题标签占位）；点明卖点或钩子，引导互动；勿编造未确认的价格或承诺。

标明适用平台；不要只交视频不交文案。

## 注意

- 无 HITL 完成前不调用出片脚本（含平台未选）。
- 不生成纯图文方案替代视频；用户只要图文则不用本技能。
- 商品类必须人物图 + 商品图都到位（提供或生成）。
- 遵守 **image-generate-edit**、**reference-to-video** 各自 skill 中的约束。
