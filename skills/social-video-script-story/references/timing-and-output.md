# 时长与交付检查

## 预算方法

1. 分离要实际说出的台词/旁白与不朗读的动作、标题和备注。
2. 根据语言、人物说话方式与情绪估算朗读时间；不能把中文字符、英文单词和标点统一按同一速度计算。
3. 添加停顿、换气、反应、辨认对象、操作与场景转换时间。
4. 只有现实可同步的动作和说话才按并行处理。需要集中操作、等待物理过程或看清结果的段落不能随意重叠。
5. 用时间范围而非伪精确单值估算；有实测朗读则优先用实测。没有实测，不声称精确到小数秒完成。
6. 对照目标删减重复、次要解释、非必要事件。保留核心信息、理解所需铺垫、结尾与锁定内容。

若要求时间轴：从零开始、连续无重叠无空洞，最后节点等于目标；同时检查每段内容是否能完成。数学上加到十五秒不代表演员能在十五秒演完。

没有给定时长时写紧凑、完整短篇，不自动输出秒数或把十五秒当永久默认。局部修改不必额外输出整片时长报告。

## 输出契约

优先用户明确格式。正文默认只给剧本，不加内部结构标签和方法解释。一个自然段故事可以包含动作与对白；口播则只包含朗读内容。详细剧本、分镜、生成提示词、字幕、发布文案分别是不同交付，只有要求时扩展。

要求“无字幕”时不加入屏幕文字或借文字解释剧情；要求“无台词”时不加旁白；要求“无声”时不依赖声音承载关键信息。各限制不可互相替代。

JSON 只输出合法 JSON；没有 schema 时只问关键字段或按用户授权选最小结构。未知事实按 schema 允许方式省略或留空，不制造值。

## 连续性检查

检查主体身份、服装、场景空间、物件数量、位置、持有者及状态。切换前后必须存在合理过渡；离开画面不等于可以任意换状态。

现实故事维持物理和行为逻辑；非现实故事维持已声明规则。物体接触、因果过程、人物视线和回应能从正文中理解。不要把大量相互冲突的动作堆在同一个时间节点。

## 最后通读

- 本次主题与目标是否被忠实执行，没有被模板或历史案例替换？
- 各段是否推进，开头承诺是否在结尾得到适当回应？
- 台词是否像人物在回应当前事件，且能自然说完？
- 动作是否有时间完成，必要停顿是否保留？
- 锁定内容与事实是否完好？
- 输出是否只有请求的内容？

内部完成检查，不默认向用户展示清单或评分。不可兼得的硬约束需要简短说明，不把冲突藏在漂亮格式里。
