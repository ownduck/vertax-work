# 来源与取舍

本技能独立综合下列公开技能的工作方法，不逐字复制，也不承诺第三方项目质量。链接用于人工溯源，不是运行依赖；无需每次联网或安装来源技能。

- https://github.com/inference-sh/skills/tree/main/guides/video/storyboard-creation
  采用景别、轴线、动作接切、视线匹配和画面方向方法。不引入其 CLI、生图流程或固定镜头数量建议。
- https://github.com/seaartpublic/skills/tree/main/storyboard-prompt-assistant
  采用保留剧情、按视觉任务拆镜、动作不过载、参考用途与文字分镜输出。去除固定时长、默认探索数量和平台流程。
- https://github.com/Arch-Dog/video-prompt-engineer
  采用定稿输入边界、声音台账、动作因果、稳定资产和独立提示词。去除 Seedance、竖屏、固定片段长度及默认声音策略。
- https://github.com/anyhui/video-storyboard-gen-skill
  采用时间线验收、连续性与可执行表格。不把故事重创作、营销结构、授权问卷或脚本工具作为必需步骤。
- https://github.com/toyme/storyboard-skill
  采用人物/场景/视觉规则分开管理、局部修正和按需读取资料。去除必需文件树和平台绑定。
- https://github.com/social-media-skills/skills/tree/main/skills/scripting-and-storyboarding
  采用声画对应、镜头目的、时间预算与制作交接。不引入发布平台、实拍排期或其他技能依赖。
- https://github.com/Krenlis/director-craft-framework
  采用可见行为、镜头任务与表演调度原则。不强制电影风格、器材参数和导演母版交付。

不采用固定八镜、九十秒三十镜、默认反转/CTA、所有镜头同背景、不区分图像与视频、声称提示词保证零畸变等规则。仓库 Star 属于仓库热度，不作为单条规则有效性的证据。
