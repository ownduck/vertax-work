# 提示词交接

## 图片提示词

每镜选择一个明确瞬间：关键动作前、接触时或结果出现后。写清主体身份/参考用途、地点、姿态、可见道具状态、景别、机位、构图、必要光线与风格。不要在一张静态图里要求先走来、再放下、最后离开。

如果需要首尾帧，分别描述两个状态，并说明同镜内动态如何连接。单镜画面、多格故事板和首尾帧是不同交付物；不默认把多格图当视频首帧。只输出文字，不实际生图。

## 视频提示词

描述：必要稳定设定 + 本镜时长 + 起点与动作目标 + 可执行过程与终点 + 景别和摄影机运动 + 原台词/声音 + 衔接要求。

逐段独立生成时，每段包含必要人物、商品、地点、道具状态；不要仅写“同上”“延续上一张”。实际提交参考或资产后可使用准确引用减小重复，但不能假定下游共享历史。

同一生成片段可以包含多个内部镜头，区分“镜头”和“生成片段”。只在用户指定或实际模型限制已知时打包；不要把十至十五秒或其他平台长度写成通用默认。不把整片台词重复到每个片段。

用户没有指定模型时输出平台中性自然语言，不添加模型 ID、seed、API 参数、特定标签或声称支持某能力。模型适配需要其已知格式；不确定时询问，不编造规格。

## 参考与限制

描述参考的用途及必须保持的特征；可用稳定引用名称，但不可假称“已上传”。参考图只展示正面时，背面关键图案不能凭空推测；若背面必须出现，进入 HITL。

负面约束只针对本镜风险，如保持手中物件数量、禁止新增图案；避免把无畸变、高清等长清单重复到每一镜。布料、水、阴影、反射遵循材质与光源；只写可信控制意图，不保证生成成功。

禁止用户要求无字幕却添加台词文字；产品自身文字可按事实保留，和额外字幕区分。台词原文属于声音信息，不能因此要求图像中出现文字。
