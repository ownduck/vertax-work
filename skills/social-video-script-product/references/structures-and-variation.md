# 结构与版本变化

## 按目标选择形式

下列为组织工具，不预设题材、情绪、品类或必须出现的桥段。

| 目标/材料 | 可用结构 | 约束 |
|---|---|---|
| 介绍商品是什么 | 识别对象 → 核心特征 → 用途/范围 | 不编未知规格 |
| 演示怎么用 | 初始状态 → 关键操作 → 结束状态 | 不用跳切伪造操作或效果 |
| 展示细节 | 整体辨认 → 具体细节 → 解释意义 | 不靠过近镜头让商品不可识别 |
| 已知真实分享 | 使用情境 → 观察 → 有范围的判断 | 不扩成普遍保证 |
| 有证据的测评/对比 | 问题 → 条件 → 观察 → 限定结论 | 不捏造测试与竞品表现 |
| 用户指定剧情 | 人物行动 → 商品参与 → 有依据的展示 → 情节落点 | 不为故事改商品或编功效 |
| 明确销售推广 | 相关需求/用途 → 已知价值与依据 → 已知行动 | 不编促销或强行恐吓 |

介绍不必须有戏剧角色，剧情不必须有反转。开箱不必须惊叫，分享不必须夸赞，评测不必须评分，推广不必须制造紧迫感。

## 变化维度

多版本可改变信息重点、展示动作、观看视角、叙述者角色、信息顺序、开头机制或结尾；保持产品事实、真实体验范围、锁定外观和用途限制。

同一商品可以共享事实，不必为每条发明新卖点。只有开头不同的 A/B 稿应称为开头版本；若用户要求完全不同的剧情，必须改变人物行动链或商品参与方式，不仅换场景和措辞。

即使只知道少量规格，也要为多个介绍版本选择不同的主要理解任务，例如识别外观、理解已知操作、判断已知容量范围；不要让每条都重复同一清单，仅调整参数朗读顺序。事实不足以支撑所需数量或范围时，进入 HITL 等用户补资料或明确调整数量/范围，不擅自交付替代稿或凑出看似不同的成稿。

## 信息与戏剧平衡

逐段检查：这段让观众了解了什么商品信息？若它只是在表演而与商品和目标无关，压缩或移除。反过来，所有对白都在背参数时，用一个必要操作或可见细节承接解释。

用户只要商品故事文案时输出完整故事，不输出广告策略。用户只要口播时输出实际要说的话。场景说明与第一人称体验必须分开处理。
